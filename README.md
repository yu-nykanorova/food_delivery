# Food Delivery
This is a learning project built for practice and portfolio purposes. A single-page React application that displays a list of food categories, meals, and restaurants.

**Live demo:** [View Live on Vercel](https://food-delivery-fawn-xi.vercel.app/)

## Features
- Built with React, Vite (with SWC), and SCSS modular styling;
- Client-side routing with React Router;
- Props-based data flow from parent to child components;
- Navigation between:
    - Main page with categories and meals,
    - Settings page (accessible via avatar click),
    - Login page (accessible via logout button in Settings),
- Responsive design for mobile and desktop devices.

## Getting Started
### 1) Clone the repository
```bash
git clone https://github.com/yu-nykanorova/food_delivery.git
cd food_delivery
```
### 2) Install dependencies
```bash
npm install
```
### 3) Start the development server
```bash
npm run dev
```
Open http://localhost:5173 to view it in your browser.

## Technologies Used
React + Vite (with SWC)
SCSS (modular)
React Router DOM

## Data Handling
- All data is stored locally in the database/ folder.
- Data is imported directly and passed to components via props.
